> System Design from Scratch: Load Balancers, Stateless Servers, Read Replicas, Caching, Queues & Sharding

An evolutionary, from-scratch approach to system design. Start with one server and one database, break it on purpose, fix exactly one thing, and repeat — until you have built the whole system and know why every piece is there and what it costs to add it.
